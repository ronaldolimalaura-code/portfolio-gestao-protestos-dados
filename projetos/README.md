# 🚀 Projetos do Portfólio

Os projetos foram organizados a partir da experiência profissional e de uma trajetória de evolução para dados, automação e tecnologia.

| # | Projeto | Principal competência |
|---|---|---|
| 01 | Controle de Cadastros | Gestão cadastral |
| 02 | CNPJs e Governos | Organização de dados |
| 03 | Automação de Planilhas | Produtividade |
| 04 | Fluxo de Protestos | Gestão de processos |
| 05 | Validador de CNPJ | Qualidade de dados |
| 06 | Dashboard Operacional | Indicadores |

## Sequência
**Cadastro → Dados → Automação → Processos → Validação → Indicadores**

Todos os projetos devem utilizar dados fictícios ou anonimizados.
