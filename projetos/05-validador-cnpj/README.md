# 05 — Validador de CNPJ

## Objetivo

Criar uma ferramenta didática para verificar a estrutura e os dígitos verificadores de CNPJs.

## Aplicações

- Conferência de bases.
- Identificação de registros inválidos.
- Preparação de dados antes de importações.
- Apoio à qualidade cadastral.

> O projeto deve usar apenas exemplos fictícios ou dados públicos apropriados.
