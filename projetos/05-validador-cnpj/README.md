# 05 — Validador de CNPJ

## Objetivo
Criar uma ferramenta didática para apoiar a conferência de CNPJs e a qualidade cadastral.

## Funcionalidades planejadas
- Verificação de formato.
- Verificação dos dígitos verificadores.
- Identificação de entradas inválidas.
- Processamento em lote.
- Relatório de resultados.

## Aplicação profissional
A ferramenta pode representar uma etapa de controle de qualidade antes de importar ou consolidar uma base.

> Usar somente dados fictícios ou dados públicos apropriados.
