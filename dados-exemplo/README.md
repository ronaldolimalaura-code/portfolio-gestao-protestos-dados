# Dados de exemplo

Os projetos deste portfólio devem utilizar somente dados fictícios ou anonimizados.

Exemplos de campos:

- `id`
- `tipo_apresentante`
- `categoria_governo`
- `status`
- `data_cadastro`
- `documentacao`
- `etapa_processo`

Nunca publicar CNPJs reais, documentos, dados pessoais, credenciais ou informações internas.
